# Support

This repository is operated as an evidence-driven engineering control plane.

## Normal support
Use GitHub Issues for reproducible defects and feature requests. Include the exact commit SHA, relevant workflow run IDs, redacted logs, and artifact hashes when applicable.

## Security issues
Do not publish credentials, exploitable vulnerability details, private datasets, signing material, recovery codes, or production configuration in public issues. Follow `.github/SECURITY.md` and use private vulnerability reporting when available.

## Support boundaries
Support will not bypass branch protection, weaken dependency/security gates, accept unverifiable build claims, or request secrets in issue comments or chat.
