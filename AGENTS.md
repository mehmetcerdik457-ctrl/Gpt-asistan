# Proje Talimatları (AGENTS.md)

## Dil kuralı

Bütün açıklamalar, raporlar, kullanıcıya yönelik sorular ve ilerleme kayıtları Türkçe olmalıdır. Kod, dosya adları, API isimleri, teknik terimler ve hata mesajları gerektiğinde özgün biçiminde korunabilir.

> Not: Bu dosya yalnızca bu depoda çalışan ajanlara/araçlara yönelik bir proje talimatıdır. GitHub hesabının genel Copilot ayarlarını veya tüm sohbetleri değiştirmez.

## Çalışma ilkeleri

- Mevcut kullanıcı değişikliklerini ve çalışan kodu koru; küçük, geri alınabilir değişiklikler yap.
- Sırları (API anahtarı, PAT, parola) kaynak koda, belgelere, loglara veya commit mesajlarına yazma.
- Çevrimdışı çalışma varsayılandır; çevrimiçi servisler isteğe bağlı olmalıdır.
- Çalıştırılmayan testi başarılı gösterme. Sonuçları PASS / FAIL / NOT_EXECUTED olarak kaydet.
- Dosya silme, veri taşıma, anahtar değiştirme gibi geri alınması zor işlemlerden önce onay al.
