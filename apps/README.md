# apps
Android uygulaması (`com.example.gptasistan`) `settings.gradle.kts` ve `.github/workflows/android.yml` `:app` yoluna bağlı olduğu için
kökteki `app/` dizininde bırakıldı (derlemeyi bozmamak için). Diğer uygulamalar (`benim-uygulamam` vb.) henüz içe aktarılmadı, bkz. `docs/MIGRATION_REPORT.md`.
